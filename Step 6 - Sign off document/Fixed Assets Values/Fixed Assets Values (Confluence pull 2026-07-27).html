Part A. What exists today

1. What it is

Shows the financial values of the organisation's fixed assets (buildings, vehicles, equipment), broken down by a chosen grouping, with the user controlling how assets are grouped and which financial figure to focus on. It is a fixed-asset register / depreciation summary.

SME A low-usage, module-dependent widget (Fixed Assets); relevant to organisations that keep a formal asset register (Marvin).

2. Where the data comes from

The Fixed Assets module. All assets, grouped by the chosen classification; selections saved per user across sessions. Verified live 23 Jul 2026 the table columns are Tag # | Name | Capitalized | Cost | Depreciable | Accumulated | Net. Context Net Book Value = Cost minus Accumulated Depreciation; cost and accumulated depreciation are kept as separate lines (preserving original cost) - which this widget does.

Part B. Users and market

5. Personas

Asset-accounting-centric. The bookkeeper / accountant (P1) uses it for depreciation and the books/audit. The treasurer / finance (P3) reads asset value and plans capital replacement. A facilities / property manager wants the inventory by building/room. Insurance / risk cares about valuation for coverage (ties to Insurance Billing). Low-usage across clients.

7. Context scenarios

A. Accountant reviews depreciation and NBV by class for the books. B. Facilities lists assets by building/room. C. Finance plans capital replacement for heavily depreciated assets. D. Insurance valuation by category. E. Year-end asset/depreciation reporting.

8. Competitor and analog benchmark

Desktop research Fixed-asset registers and depreciation reporting (Sage Fixed Assets, NetSuite FAM, nonprofit asset registers) center on Net Book Value (cost less accumulated depreciation), grouping by class/location, and a cost -> accumulated depreciation -> NBV read per category. Nonprofits use straight-line depreciation and monitor NBV to anticipate replacement as assets near end of useful life (capital planning), plus donor/insurance transparency. Sources: Truewind (cost vs accum deprec), Pascual (NBV, replacement planning), CPCON (register fields), AssetCues.

Part C. Designer brief

9. Target composition (what the widget should be built from)

The concrete make-up, so it can be built and demoed consistently. A floor, not a straitjacket. Triage: P current production (keep what works, delete nothing used), C competitor, SME Ben Lane, DR desktop/best practice, O Oisin's demo.

Controls (header):

  • Grouping selector (Class / Building / Room / Asset Account / Accumulated Depreciation Account) and chart-metric picker (the five measures), saved per user - keep the flexibility; remove the "None" option that shows nothing (default to Class). Refresh with a "data as of" timestamp. [P verified live 23 Jul 2026; None still an open question]

Views:

  • Glance (KPI): total cost, total accumulated depreciation, total Net Book Value, asset count, and % depreciated (a capital-planning proxy). [DR]

  • Breakdown chart: a bar by group for the selected measure (clearer than the current chart), and ideally a cost / accumulated depreciation / NBV comparison per group (stacked or grouped) so the depreciation story shows in one view. [DR; improves the P metric-driven chart]

  • Table (keep): assets in the group with all seven columns (Tag # | Name | Capitalized | Cost | Depreciable | Accumulated | Net) + totals; selected measure emphasised. Wide table - prioritise the key columns at a glance. [P verified live 23 Jul 2026]

Interaction & rules:

  • Preserve the synced table+chart and flexible grouping. [P strengths, verified live 23 Jul 2026]

  • Surface % depreciated to flag assets near end of life (replacement planning). [DR]

  • Fix the £ hardcoded currency to follow the org (localisation defect). Values as text; named controls; keyboard. [accessibility]

  • Optionally link an asset row to its record. [enhancement]

11. Significant design decisions

11.1 Lead with Net Book Value + a KPI - total cost / accumulated depreciation / NBV / % depreciated, so the portfolio value reads at a glance. 11.2 Show the depreciation story - a cost / accumulated-depreciation / NBV comparison per group beats a single-measure chart. 11.3 Bar over pie for the group breakdown. 11.4 Add % depreciated for replacement planning. 11.5 Remove the dead "None" grouping option. 11.6 Preserve the flexible grouping and sync (strengths). 11.7 Accessibility parity and fix the £ localisation defect.
