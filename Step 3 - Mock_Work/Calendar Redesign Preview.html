W09 Leave Calendar — redesign preview

Before and after, at both tiers, from the same data. Nothing in the live build has changed — this is a preview so you can judge it first. The day popover, Group by and the status filters are untouched by this proposal.

What changes. A uniform row floor so weeks stop being ragged (and the +N chip can never be clipped); day number up from 9px to 11px, the file’s norm, and moved top-left; one status channel — the left accent bar — freeing the background for hover and selected, which the cell previously had no room for; today gets a pill on the number instead of a thicker border that resized the cell; and tiered chrome, so Explore and Detail are no longer the same drawing stretched. The tint is reserved for Outstanding alone, so the one loud thing on the month is the state that needs acting on.
